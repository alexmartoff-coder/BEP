# BEP — Сервис генерации коммерческих предложений (КП)

Автоматизированная система подготовки и расчета стоимости коммерческих предложений на электрощитовое оборудование по техническим спецификациям и прайс-листам.

Проект разработан с использованием **FastAPI** для бэкенда и чистого **HTML + CSS + JS** для фронтенда. Подготовлен к автоматическому деплою на **Railway**.

---

## 🏗️ Структура проекта

│   ├── style.css             # Стили оформления (вкладки, формы, таблицы)

## ✨ Основные функции

1. **Расчет КП из Excel (Спецификация + Прайс)**:
   - **Техническая спецификация**: автоматический разбор позиций оборудования, артикулов, количества и группировка по щитам/шкафам (например, СШ3 ТП1, ЩАВР 1200А, и др.).
   - **Прайс-лист CHINT**: поиск цен с НДС по артикулу или наименованию.
   - **Генерация КП**: расчет стоимости по каждой позиции, вывод промежуточных сумм по разделам/щитам и итоговой общей суммы.
   - **Скачивание**: экспорт сформированного коммерческого предложения в виде красивой, отформатированной Excel-таблицы с рамками, цветами и формулами сумм.

2. **Анализ PDF-спецификаций (OCR)**:
   - Извлечение текста из PDF файлов с помощью библиотеки `pdfplumber`.
   - Резервное распознавание отсканированных документов (OCR) с помощью `pytesseract`.
   - Автоматический поиск электрощитовых позиций, контакторов, автоматов, реле и клемм.

## 🚀 Как запустить локально

### 1. Подготовка окружения

Убедитесь, что у вас установлен **Python 3.11** или новее.

Создайте и активируйте виртуальное окружение:

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация на macOS/Linux:
source venv/bin/activate

# Активация на Windows (cmd):
venv\Scripts\activate.bat
```

### 2. Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 3. Создание файла конфигурации

Скопируйте пример файла окружения:

```bash
cp .env.example .env
```

### 4. Запуск сервера

Запустите FastAPI сервер с помощью uvicorn:

```bash
uvicorn backend.main:app --reload --port 8000
```

После запуска:
* **Фронтенд** будет доступен по адресу: [http://localhost:8000/](http://localhost:8000/)
* **Интерактивная API Документация (Swagger)**: [http://localhost:8000/docs](http://localhost:8000/docs)

## 🛠️ Основные эндпоинты API

### `POST /api/generate-kp`
Принимает техническую спецификацию Excel и прайс-лист Excel, возвращает подробный расчет КП.
* **Request Header**: `Content-Type: multipart/form-data`
* **Form Data**:
  - `specification`: Файл Excel со спецификацией
  - `pricelist`: Файл Excel с прайс-листом CHINT
* **Response**:
  ```json
  {
    "status": "success",
    "specification_file": "spec.xlsx",
    "pricelist_file": "price.xlsx",
    "kp": {
      "boards": [
        {
          "board_name": "ЩАВР 1200А",
          "items": [
            {
              "article": "CHINT-001",
              "name": "Контактор...",
              "qty": 2,
              "unit": "шт",
              "price": 12500.00,
              "total": 25000.00,
              "price_found": true
            }
          ],
          "subtotal": 25000.00
        }
      ],
      "grand_total": 25000.00
    }
  }
  ```

### `POST /api/export-kp`
Принимает JSON-структуру КП и возвращает отформатированный, готовый для печати файл `.xlsx`.
* **Request Header**: `Content-Type: application/json`
* **Body**: JSON-структура `kp` (с полями `boards` и `grand_total`)
* **Response**: Файл `preliminary_commercial_proposal.xlsx` (attachment).

## ☁️ Деплой на Railway

Проект полностью готов для деплоя на платформу **Railway**:
1. Он автоматически настраивает системные библиотеки для OCR (`tesseract-ocr`, `poppler-utils`) с помощью `Dockerfile`.
2. Конфигурирует деплой согласно правилам `railway.toml`.
3. Мониторит работоспособность через эндпоинт `/api/health`.
