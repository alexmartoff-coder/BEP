# База знаний: обозначения на электрических схемах (по ЕСКД / ГОСТ 2.709, 2.721 и практика щитов)

## A. Что НЕ является оборудованием для КП (не добавлять в BOM)
1. L1, L2, L3 — фазные проводники/цепи, не аппарат.
2. N — нулевая рабочая цепь, не аппарат.
3. PE, PEN — защитные цепи, не аппарат.
4. Обозначения цепей вида «гр.1ЩС…», «-1», «-2» — маркировка цепей/групп, не позиция прайса.
5. Подписи «Сортер РУ-…», «Резерв» как назначение линии — не отдельный автомат, если нет QF с номиналом.
6. Длины кабеля (L=… м, L*=… м) — не оборудование.
7. Падение напряжения ΔU, ΔU* — не оборудование.
8. Мощности Ру, Рр, Руст, Ррасч и токи Iр без QF — расчётные величины, не аппарат.
9. Кс (коэффициент спроса) — не оборудование.
10. Уставки: «уст.», Ir, Iтр, Isd, Iэр, значения 441А, 4410А в контексте уставки — не отдельные автоматы.
11. QF 504А с пометкой «уст.» — уставка, не позиция BOM (если не указан как отдельный аппарат к установке).
12. Номера на плане, инвентарные и штамп (Разраб., ГИП, лист, формат) — не оборудование.
13. Адреса, кадастровые номера, название объекта — не оборудование.
14. Высота установки (например 1300 мм) — не оборудование.
15. Марки кабеля (ВВГнг, ППГнг, КГВВнг и сечение 5х50, 1х240) — кабель, не автомат CHINT из прайса щита (в BOM щита не включать как QF).

## B. Что ЯВЛЯЕТСя оборудованием для КП
16. QF, QF1, QF2, … QFn — аппараты защиты/коммутации; брать номинал Iн (А) и полюса (1P, 3P, 4P, 1P+N).
17. 1QF на вводе щита — вводной автомат; типично 630А 3P, если указано на схеме.
18. Позиция в BOM: тип (авт. выкл.), полюса, ток (А), количество; не путать с обозначением цепи.
19. Несколько QF с одинаковым током и полюсами — суммировать qty.
20. Резервные QF с указанным номиналом и полюсами — включать в BOM.

## C. Как читать схему (кратко)
21. Ряд подписей QF1…QFn и ряд токов (…А) и ряд полюсов (1P/3P) сопоставлять по порядку (колонкам).
22. Не брать ток из соседних расчётных полей (Iр, Ру), если он не подписан у QF.
23. Не создавать позиции 6А/10А из случайных цифр («5», «кА», кривая), если нет явного «6А»/«10А» у QF.
24. Обозначения общего применения на схеме (линии связи, экраны по ГОСТ 2.721) — не позиции прайса.
25. «Выключатель нагрузки» / «разъединитель» добавлять только если явно подписаны; QF по умолчанию = автоматический выключатель.

## D. Связь с прайсом CHINT
26. В прайсе искать «Авт. выкл.», не «выключатель нагрузки» и не «разъединитель», если на схеме QF.
27. Для 1P не подставлять 3P/3P+N; для 3P не подставлять 1P.
28. Цена — из колонки тарифа/цены с НДС; артикул — код, не «Промышленная» и не номер QF.
29. Если номинал есть, а артикул не найден — оставить позицию с ценой 0 и наименованием по схеме.
30. Итог КП: только аппараты щита (и согласованные позиции), без цепей L/N/PE, без уставок и без штампа.

## E. Приоритет источников
31. Если из текста/геометрии схемы собран устойчивый список QF+ток+полюса — он главнее «догадок» по общим словам страницы.
32. ГОСТ используется для фильтрации и понимания обозначений, а не для назначения цен.
